# 系统模式（个人 / 标准 / 专业）产品方案

## 1. 背景与目标

### 1.1 观察到的现状

MyBooks 当前是一套按「多用户 / 社区化」前提构建的完整系统：

- 首次安装只要求站点名、语言、管理员账号、是否私人图书馆，其余能力一律默认开放（见 [install.vue](/app/src/pages/install.vue)）。
- 系统设置页一次性呈现 8 个分组、30+ 个设置区块（站点与外观、阅读与内容、用户与访问、导入与存储、服务与集成、协议与接口、推送与设备、运维与性能，见 [settings.vue](/app/src/pages/admin/settings.vue#L1635-L2424)），面向多用户的选项（访客权限、注册审批、下载配额、社交登录、留言管理、缺书登记、书单、友情链接等）与个人自用选项混在一起。
- 右上角的「外观」面板提供 12 种背景、8 种主色、品牌色、圆角、侧边栏图标模式等细粒度项（见 [AppearanceMenu.vue](/app/src/components/AppearanceMenu.vue#L250-L268)）。

### 1.2 受影响的人群与场景

个人版本面向单用户：一台到几台设备、一个账号、几千本的电子书。标准版本面向家庭或小团队：使用者为少量用户。两者都不涉及社区运营，日常只关心「把书放进来 → 在线阅读/推送到阅读设备 → 记录进度」，不需要访客权限、注册审批、社区书单、第三方登录，也不希望这些入口和设置项出现在界面上。

### 1.3 产品决策

引入一个**全局「系统模式」标识**，作为全站能力开关的唯一真值来源。系统模式分三档：

- **专业版本（Pro）**：维持当前完整形态，全部能力开放、全部设置可见、外观可细粒度调节；特性清单**全部锁定选中，不提供反选**。
- **标准版本（Standard）**：面向家庭或小团队（少量用户），在核心能力之外保留「常用功能」特性，用户账号由管理员在用户管理中创建；为多用户/社区设计的特性与运维/高级特性默认关闭、入口隐藏、设置项不显示。
- **个人版本（Personal）**：面向单用户，不需要用户注册，也不提供用户管理，安装时在第一页指定管理员账号即可；在核心能力之外保留个人的常用功能（取书/送书、阅读进度与统计）。

安装入口直接进入**配置引导**，它替换并集成原安装页（`/install`）：第一页填网站名称、默认语言、管理员用户名/密码/邮箱与访问控制；第二页选择系统模式与功能项；第三页配置刮削信息。第一、二页为安装必需、不可跳过，第三页可跳过。系统设置提供**系统模式配置**入口，只负责选择模式与启停功能项。模式决定「本模式允许涉及的特性范围」与默认勾选集，用户可在范围内调整。

### 1.4 期望的可观察结果

- 个人与小团队用户从安装到日常使用，界面上只出现其会用的能力；不需要的特性既没有入口、也不出现在设置里。
- 同一套前端/后端能力，通过一个全局标识即可决定「显示什么、开放什么」，无需逐个功能改造。
- 用户可随时在个人 / 标准 / 专业之间切换，切换可逆、已有数据不丢失。

## 2. 术语与产品模型

| 术语 | 定义 |
| --- | --- |
| 系统模式 | 全局能力预设，取值三档：`个人版本（personal）`、`标准版本（standard）`、`专业版本（pro）`。全局唯一，被安装向导、系统设置、前端呈现共同引用。 |
| 特性（Feature） | 可开关的最小能力单元，是引导与设置中「勾选项」的粒度。 |
| 特性清单 | 全部特性的集合及其分类，是安装向导与系统设置共用的同一份清单。 |
| 特性范围 | 某一模式下允许涉及的特性集合。个人/标准只在各自范围内可选；专业范围为全部。 |
| 全局模式标识 | 系统模式在站点信息中的全局下发字段，供全站（导航、右上角菜单、首页板块、外观面板）读取，记为 `systemMode`。 |

### 2.1 三档模式与特性的关系

| 模式 | 特性范围 | 默认勾选 | 可否调整 |
| --- | --- | --- | --- |
| 个人（personal） | 核心 + 常用功能（第 3.2 节） | 核心（必开）+ 阅读进度/数据同步 + 阅读统计与仪表盘 | 可在本模式范围内勾选其它常用功能 |
| 标准（standard） | 核心 + 常用功能（第 3.2 节全部） | 核心（必开）+ 常用功能全选；OPDS、WebDAV、实体书登记默认关闭 | 可在本模式范围内调整 |
| 专业（pro） | 全部特性 | 全部 | **锁定全选，不可反选** |

模式是「预设」：切换模式即把特性清单重置为该模式的范围与默认勾选集，随后用户可在该模式范围内微调（专业模式除外，专业锁定全选）。

**范围外特性不可见**：个人/标准模式下，多用户/社区与运维/高级特性不在可选范围内，界面上不出现、不可勾选；只有切到专业模式才会出现。

**账号体系随模式变化**：个人版本只有安装时指定的那一个账号，没有注册入口，也没有用户管理界面；标准版本由管理员在用户管理中创建账号（少量用户），同样不开放自助注册；自助注册只在专业版本出现。

**强制登录访问不属特性清单**：它由配置引导第一页的访问控制项写入 `REQUIRE_LOGIN`，不进入第二页的功能勾选，也不计入任何模式的默认勾选集。原安装页的私人图书馆访问码 / 邀请（`INVITE_MODE`、`INVITE_CODE`）同样不进入引导，仍归运维/高级特性、仅专业版本可用。

### 2.2 特性开关的生效规则（三通道一致）

一个特性被判定为「未选中」时，三件事同时发生：

1. **能力不开放**：后端对应的设置开关置为关闭，接口/服务不再对外提供。
2. **入口隐藏**：导航、右上角菜单、首页板块、页面路由入口不再出现。
3. **设置不显示**：该特性在系统设置中的区块（section）不再渲染，也不进入设置搜索索引。

三通道必须一致，任一通道单独遗漏都会造成「入口还在但点不开」或「设置能改但界面没反应」的错位。

## 3. 功能分类

分类口径按「个人与小团队是否大概率使用」划分：

- **核心（Core）**：三档模式都保留，不提供开关。
- **常用功能（Personal）**：个人大概率使用，标准版本默认全选；个人版本默认只勾选「阅读进度/数据同步 + 阅读统计与仪表盘」，其余可在本模式范围内自行勾选。
- **多用户/社区（Community）**：为多用户场景设计，个人/标准模式默认关闭并隐藏；仅专业版本可用。
- **运维/高级（Advanced）**：安装部署与高级玩法相关，个人/标准模式默认关闭并隐藏；仅专业版本可用。

### 3.1 核心能力（各档模式必开，不可关闭）

| 特性 | 主要入口 | 关联设置项 |
| --- | --- | --- |
| 书库浏览与检索（全部书籍、分类、标签、作者、出版社、系列、语言） | 首页、顶栏导航 | `SIDEBAR_ITEMS`、`BOOK_NAV` |
| 在线阅读（EPUB / PDF / DJVU / TXT / FB2 阅读器） | 书籍详情、阅读页 | `EPUB_VIEWER` |
| 上传与导入（上传、扫描导入、批量导入、元数据补全） | `/admin/imports`、上传对话框 | `IMPORT_CATEGORY_WITH_FOLDER`、`META_SELECTED_SOURCES` |
| 书籍管理后台 | `/admin/books` | — |
| 个人阅读状态（在读 / 待读 / 读完 / 收藏 / 浏览历史） | 顶栏「阅读信息」 | — |
| MyNexus AI 解析与伴读（书籍解析、伴读问答） | 书籍详情页、阅读器内 | `ENABLE_MYNEXUS`、`MYNEXUS_URL`、`MYNEXUS_TOKEN` |
| 站点基础信息（站点名、图标、语言、时区、页脚、公告） | `/admin/settings` 站点分组 | `site_title`、`site_icon`、`site_language`、`site_timezone`、`FOOTER`、`HEADER` |
| 系统设置页本体 | `/admin/settings` | — |

> 用户与账号不属核心：个人版本是单账号、没有用户管理；书籍详情也不展示私藏书籍相关的按用户分组能力，因此账号管理只在需要多账号的模式（标准、专业）出现，见 3.2。

### 3.2 常用功能（标准版本默认全选；个人版本默认只勾选同步与阅读统计；专业全开）

| 特性 | 分类理由 | 个人 | 标准 | 主要入口 | 关联设置项 |
| --- | --- | --- | --- | --- | --- |
| 阅读进度 / 数据同步（跨设备续读） | 个人多设备刚需 | ✓ | ✓ | 阅读器内同步 | `ENABLE_DATA_SYNC`、`MYREADER_SYNC_PATH` |
| 阅读统计与仪表盘（热力图、时长、书量） | 个人自用反馈，与进度同步一并查看 | ✓ | ✓ | 首页 banner | `ENABLE_HOMEPAGE_READING_STATS`、`ENABLE_HOMEPAGE_READING_BOOKS`、`ALLOW_USER_DISABLE_STATISTIC` |
| 推送到阅读设备（Kindle / 文石 / 掌阅 / 汉王 / KOReader 等） | 个人最常用的送书方式 | — | ✓ | 详情页「推送」 | `DEVICES`、`push_title`、`push_content` |
| WebDAV 服务 | 默认关闭；个人用第三方阅读器同步 | — | — | `/admin/settings` 协议分组 | `ENABLE_WEBDAV_SERVICE`、`WEBDAV_SYNC_FOLDER` |
| OPDS 目录 | 默认关闭；个人用静读天下等客户端取书 | — | — | `/opds-readme` | `ENABLE_OPDS_SERVICE`、`ENABLE_OPDS_AUTH` |
| 账号管理（创建/停用账号） | 标准版本少量用户需要账号管理；个人版本为单账号 | — | ✓ | `/admin/users` | — |
| 评论、评分与阅读批注 | 个人自用与少量用户都需要，个人可自行标记，标准/专业可交流 | — | ✓ | 书籍详情页评论区、`/admin/book-reviews` | `ENABLE_BOOK_REVIEW`、`REVIEW_REQUIRES_APPROVAL`（审核默认关） |
| 有声书 / 音频 | 个人听书 | — | ✓ | `/audiobooks` | `ENABLE_AUDIO_SUBTITLE`、音频转换、详情页中有声书的展示、图书管理中的有声书导入、`ENABLE_PODCAST_SERVICE` |
| 实体书登记 | 个人纸质藏书登记；标准默认不勾选 | — | — | `/printbooks` | `ENABLE_PHYSICAL_BOOKS`、`ENABLE_BOOKS_TYPE_CONVERT_DIRECT` |
| 文件夹层级浏览（按服务器目录结构浏览藏书） | 个人整理多级目录也需要；标准默认开，个人可开启 | — | ✓ | `/folder` | `ENABLE_FOLDER_BROWSE` |
| 自己部署 MyDict 词典服务（划词查询） | 阅读辅助，个人高频 | — | ✓ | 阅读器内词典 | `READER_MYDICTS`、`READER_DICT_MYBOOKS_ENABLED`、`READER_DICT_BAIKE_ENABLED` |

> 默认勾选按模式区分：标准版本默认全选上表（OPDS、WebDAV、实体书登记默认关闭）；个人版本默认只勾选「阅读进度/数据同步 + 阅读统计与仪表盘」，其余默认关闭、可在个人模式范围内自行勾选。OPDS、WebDAV 与实体书登记在两种模式下均默认关闭，需要时手动开启；播客随有声书，标准默认开、个人默认关可开启。
>
> 评分与评论均属常用功能，不做专业/常用拆分：`ENABLE_BOOK_REVIEW` 一个开关同时控制评分与评论，个人/标准默认关闭审核、提交即生效；标准/专业可按需开启「先审后发」。评论管理入口 `/admin/book-reviews` 随该特性一起出现。

### 3.5 全量设置项与管理功能清单（归类底表）

本节从代码反向盘点，确保「所有设置都在考虑范围内」：

- 覆盖 [settings.vue](/app/src/pages/admin/settings.vue) 的 8 个分组、31 个小节及其全部字段与特殊块；
- 覆盖 [books.vue](/app/src/pages/admin/books.vue) 的书籍管理功能；
- 覆盖 [_bookid.vue](/app/src/pages/book/_bookid.vue) 的书籍详情管理功能；
- 补充设置页未暴露、但会影响运行行为的后端配置项（3.5.6）。

归类口径沿用第 3 节：**核心**、**常用**、**专业·社区**、**专业·高级**；后两者合并即「专业版才会使用」。标注「引导项」的字段不进入特性清单，由配置引导第一页直接写入。

## 4. 个人/标准模式下相关特性的隐藏规则

留言、缺书登记、书单、友情链接、社区账号这五类特性都命中三通道：特性未选中时，能力关闭、入口隐藏、设置不显示，数据保留。它们逐项的隐藏对象如下。

| 特性 | 隐藏的入口 | 不显示的设置区块 | 一并关闭的能力 | 已有数据 |
| --- | --- | --- | --- | --- |
| 站内留言 | 侧边栏「站内留言」（`/memos`）、用户菜单留言入口、书籍详情留言区；管理员「留言管理」（`/admin/user-memos`） | 站点与外观分组中的留言开关与留言审核项 | 留言提交、留言列表、留言审核 | 留言记录保留，不对外展示 |
| 缺书登记 | 顶栏/用户菜单「缺书登记」（`/expected`）；管理员「缺书管理」（`/admin/all-expected`） | 无独立区块，随特性开关 | 提交缺书登记、缺书列表、「缺书转图书」 | 登记记录保留 |
| 书单 | 首页书单板块、`/booklists/*`（公共/收藏/我的书单）、详情页「加入书单」 | 站点分组中「首页书单推荐」及书单相关项 | 书单增删改查接口 | 书单与条目保留 |
| 友情链接 | 顶栏「友情链接」入口 | 站点分组的友情链接配置区块（`FRIENDS`） | 纯前端展示，隐藏即关闭 | 已配置的链接文案保留 |
| 社区账号 | 登录/注册页的第三方登录按钮 | 站点分组的社交登录配置区块（`SOCIALS`） | 第三方 OAuth 回调路由 | 已绑定关系保留，升档后仍可登录 |

书单被隐藏时，依赖书单的首页书单推荐、详情页「加入书单」、协同过滤中依赖书单的信号一并按关闭处理，避免出现「书单没了但推荐还在引用」的错位。

专业版本默认全选，意味着上述五类特性在专业版本下全部开启，入口、设置区块与后端能力照常可用；个人/标准版本只是把它们从默认勾选里拿掉并隐藏。两者不是两套独立代码，而是同一份特性清单的两种勾选结果：同一个特性在全站只存在一处开关真值，模式只决定这个真值被预设成什么。从标准切到专业即恢复全选，切回标准再隐藏，来回切换不改动数据，也不覆盖用户对其它设置的手工修改。

## 5. 安装配置引导

安装入口即**配置引导**：它替换并集成原安装页（`/install`），把安装页原有的站点名称、默认语言与管理员账号能力并入引导流程，再串联系统模式、功能项与刮削信息。第一、二页为安装必需、不可跳过，第三页可跳过（跳过 = 采默认值），之后都可在系统设置里补。

![安装配置引导原型：站点基础与账号 → 系统模式与功能项 → 刮削信息配置 三步向导（替换并集成原安装页 /install）](images/install-guide-wizard.png)

### 5.1 引导步骤

1. 站点基础与管理员账号（必需）：填写网站名称（`site_title`）、默认语言（中 / 英，`site_language`），以及管理员用户名、密码、邮箱；并设置访问控制项「必须登录才能访问」（`REQUIRE_LOGIN`，默认关闭）。这些是安装必需信息，不可跳过；私人图书馆访问码 / 邀请不在此步出现（见 2.1）。
2. 系统模式与功能项（必需）：选择三档模式（个人 / 标准 / 专业），并按当前模式范围勾选要启停的功能项。
   - 不显示用户名：个人版本直接使用第一页设置的管理员账号登录，不再单独指定账号，也不出现注册；标准版本的账号由管理员后续在用户管理中创建。
   - 不显示「强制登录访问」：该开关已在第一页的访问控制项里设置，功能项列表不再重复。
   - 个人版本：核心项固定勾选且置灰；常用功能默认只勾选「阅读进度/数据同步 + 阅读统计与仪表盘」，其余默认关闭、可在范围内勾选。
   - 标准版本：核心项固定勾选且置灰；常用功能默认全勾选，其中 OPDS、WebDAV 与实体书登记默认关闭，可调整。
   - 专业版本：全部特性勾选且锁定不可修改。
   - 多用户/社区与运维/高级特性在个人/标准模式下不展示。
3. 刮削信息配置（可跳过）：选择是否自动刮削（`auto_fill_meta`、`AUTO_FILL_META`），以及刮削信息源（`META_SELECTED_SOURCES`，缺省用 `DEFAULT_META_SOURCES`）。

### 5.2 引导规则

- 引导即安装入口：原独立安装表单（`/install`）由引导替换，第一页接管站点名、语言与管理员账号的校验（沿用安装页规则：用户名 3–20 位、密码 6–20 位、邮箱格式）。
- 第 1、2 页必需且不可跳过（第 1 页写入安装必需信息与 `REQUIRE_LOGIN`，第 2 页写入全局模式标识 `systemMode` 与特性勾选结果），第 3 页可跳过（跳过 = 采默认值）；每页都可返回上一步修改。
- 引导内对每个功能项给出「开启后会出现在哪里」的一句话说明，避免用户盲选。
- 完成后跳转首次进入检查；模式、功能项与常见配置项之后都能在系统设置中再次修改，两处是同一份真值。

## 6. 系统设置中的系统模式配置

### 6.1 入口与位置

系统设置提供「系统模式配置」入口，放在设置页顶部操作行的左侧，与现有「社区」「使用手册」按钮同一行（见 [settings.vue](/app/src/pages/admin/settings.vue#L1-L22)）。系统模式配置只做两件事：选择系统模式、启停功能项。

- 选择模式：个人 / 标准 / 专业三档，切换即重置特性范围与默认勾选集（专业锁定全选）。
- 启停功能项：按分类勾选，仅展示当前模式范围内的特性；个人/标准模式不出现多用户/社区与运维/高级特性。
- 外观组合不在这里，属于右上角「外观」面板（见第 8 节）。

个人/标准模式下，管理员能看到的也只有这个入口，而不是全部设置：被隐藏的设置区块对管理员同样不显示，需要时先切到专业版本再配置。

### 6.2 设置页的呈现规则

- 特性关闭则对应设置区块不显示：被关闭特性所对应的设置区块不再渲染，例如友情链接、社交登录、推送设备区块、播客，以及用户分组中的访客权限/配额/注册审批/新用户默认权限、运维分组中的 SSL/性能/缓存/回收站等。
- 用户分组随账号模式变化：个人版本不显示用户管理与注册相关区块；标准版本只显示账号管理，注册与审批相关项仍隐藏。
- 设置搜索索引同步收缩：设置页搜索（`flatIndex` / `SPECIAL_BLOCKS`，见 [settings.vue](/app/src/pages/admin/settings.vue#L1099-L1128)）只索引当前可见特性的字段，避免搜出已被隐藏的项。
- 关闭的特性数据保留：数据不删除，仅隐藏入口与设置；切回更高档模式即恢复（见第 9 节）。
- 依赖关系提示：当某特性依赖另一特性（如「首页书单推荐」依赖「书单」，「协同过滤推荐」依赖多用户行为），父特性未勾选时，子项置灰并给出原因提示。

## 7. 全局模式标识与前端呈现

### 7.1 标识定义

- 全局标识 `systemMode ∈ {personal, standard, pro}`，与特性勾选结果一起持久化，并随站点信息（`sys`）一并下发，前端任何位置都能读到。
- 前端以站点信息为唯一来源决定可见性（导航、右上角菜单、首页板块、外观面板），不在各页面里散落判断逻辑。

### 7.2 前端受影响的位置

| 位置 | 个人/标准模式下的变化 |
| --- | --- |
| 顶栏导航 / 侧边栏 | 隐藏留言、书单、缺书登记、浏览记录、友情链接等入口 |
| 右上角用户菜单 | 隐藏缺书登记、留言相关项 |
| 管理员菜单 | 隐藏留言管理、缺书管理、分享管理、工具箱等入口；个人版本额外隐藏用户管理；评论管理随「评论与评分」特性开关显示，不再默认归专业 |
| 首页板块 | 按特性隐藏书单推荐、推荐给他人等板块 |
| 右上角外观面板 | 由细粒度改为组合选择（见第 8 节） |
| 系统设置页 | 隐藏被关闭特性的区块与搜索项，并保留顶部的系统模式配置入口 |

## 8. 个人/标准模式：右上角外观组合

专业版本保持现有全部细粒度外观项（深浅色、主色、品牌色、12 种背景、圆角、侧边栏图标模式）。

个人/标准模式将外观收敛为三套固定组合，用户默认只在组合间切换；同时保留一个「高级」展开入口，展开后仍可访问现有细粒度项。

| 组合 | 深浅 | 主色 | 背景 | 圆角 |
| --- | --- | --- | --- | --- |
| 明亮极简 | 浅色 | 蓝 | 默认 | 4px |
| 深色沉浸 | 深色 | 蓝灰 | 极光渐变 | 8px |
| 暖色护眼 | 浅色 | 橙 | 暖色渐变 | 16px |

默认折叠为组合选择，点「高级」后展开细粒度参数（与专业版本面板一致）。组合选择仅覆盖个人账户级外观，不影响站点默认。

## 9. 共享规则与例外

| 规则 | 说明 |
| --- | --- |
| 关闭 ≠ 删除 | 关闭特性只隐藏入口、关闭能力、隐藏设置项；不删除任何已有数据。切回更高档模式即恢复可见与可用。 |
| 切换可逆 | 个人 ↔ 标准 ↔ 专业可随时切换（专业仅可切出），切换只重置特性范围与默认勾选集，不覆盖用户对其它设置的手工修改。 |
| 专业锁定 | 专业版本特性清单锁定全选，安装引导与系统设置中均不可反选，保证「专业 = 完整能力」。 |
| 范围外不可见 | 个人/标准模式下，范围外特性（多用户/社区、运维/高级）在清单中不出现、不可勾选，仅在专业版本出现。 |
| 账号体系随模式 | 个人版本单账号、无注册、无用户管理；标准版本由管理员管理少量用户账号；自助注册仅专业版本。 |
| 单一真值 | 全局模式标识与特性清单是判断的唯一来源，任何新功能都需登记到清单中（分类、入口、关联设置项），否则轻模式下会「漏开关」。 |
| 默认值守卫 | 关闭某特性时，其派生/关联开关的运行时取值需一并按关闭处理（例如关闭评论时，推荐引擎的「参考评论」信号应视作关闭），避免出现「设置关了但引擎仍在使用」的隐形行为。 |
| 老实例升级 | 已安装实例升级到本版本时默认保持专业版本，不改变既有行为，由用户主动选择是否降档。 |
| 管理员视角 | 个人/标准模式下，被关闭特性的入口与设置区块对普通用户与管理员一并隐藏，管理员只保留顶部的模式切换入口。 |
